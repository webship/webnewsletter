# Test Screenshots

Failure screenshots captured during test runs are stored here and excluded from version control.

Files follow the naming pattern:
- webship-js: `failed_<timestamp>.<feature>_<line>.png` / `.html`
- Playwright: captured automatically on test failure (see `screenshot: 'only-on-failure'` in `playwright.spec.config.ts`)

These files are generated automatically — do not commit them.
